# Project 03 - Alpha Channel

## Description

This project demonstrates how to work with an image that contains an Alpha channel.

The program loads an image with transparency, separates the BGR and Alpha channels, converts the image to RGB, and displays it.

## Requirements

- Python
- OpenCV
- NumPy
- Matplotlib

## How to Run

```bash
python opencv_project03.py
